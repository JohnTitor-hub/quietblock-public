Build from source

Extract the source ZIP. Use Node 24.4.0, npm, Python 3, and a C++ build toolchain. From the extracted directory: 

npm ci
npm run build

The resulting dist/ directory can be loaded through Chrome's Load unpacked control. The archive's README contains installation, testing, and filter-maintenance instructions.
