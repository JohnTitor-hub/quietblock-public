# Quietblock public files

A small ad-filtering extension with local controls and no product telemetry.

This repository contains Quietblock's static privacy, support and versioned source-download website.

Publisher: Quietblock. Repository owner: `JohnTitor-hub`. Website: https://johntitor-hub.github.io/quietblock-public/.

Complete matching source archives and SHA-256 checksums are in `downloads/`. Use those versioned archives to rebuild the extension; GitHub's automatic source archive for this website contains only the website files. Each extension source archive includes build instructions, licenses, modification notices and preferred dependency sources.

Public contact: quietblockcontact@gmail.com. License and component notices are in `licenses/`.
